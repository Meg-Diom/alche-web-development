CSS, Advanced

Project Overview

This project focuses on styling and improving an existing HTML webpage using CSS. It follows the HTML, Advanced project and builds upon the HTML structure developed previously.

The main objective is to recreate a webpage based on a professional design provided through Figma, paying close attention to layout, typography, colours, spacing, images, and responsiveness.

Learning Objectives

By completing this project, I aim to:

- Understand how CSS works with HTML.
- Apply CSS selectors and styling properties effectively.
- Understand and implement the CSS box model.
- Work with margins, padding, borders, and positioning.
- Create layouts using modern CSS techniques.
- Reproduce a professional webpage design using Figma as a reference.
- Improve the visual appearance and consistency of an existing HTML page.
- Write clean, readable, and maintainable CSS.

Technologies Used

- HTML5 – Provides the structure and content of the webpage.
- CSS3 – Handles the styling, layout, and visual presentation.
- Figma – Provides the original design specifications and visual reference.

Requirements

- Reuse the `index.html` file from the HTML, Advanced project.
- Implement the styling using CSS.
- Follow the supplied Figma design.
- Maintain clean and organised code.
- Ensure the webpage displays correctly in a web browser.
- Avoid unnecessary changes to the existing HTML structure.

Getting Started

1. Clone or download the project repository.
2. Open the project directory in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Implement and refine the styles in `styles.css`.
